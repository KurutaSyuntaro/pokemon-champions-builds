# メガラグラージ＋メガキラフロル軸ダブルバトル構築 M-B

## レギュレーション

- **レギュレーション**: M-B
- **ステータス**: 構築中
- **期間**: 2026年6月17日（水）～ 2026年9月2日（水）10:59
- **対戦形式**: ダブルバトル
- **メガシンカ**: 使用可能（1バトルにつき1匹まで）
- **持ち物**: チーム内で同じ持ち物は不可
- **制限時間**: 総合20分 / 持ち時間7分 / 選択時間45秒 / チーム選択90秒

## コンセプト

> **メガラグラージ（すいすい）＋メガキラフロル のメガ2枠雨パ**。ペリッパーで即時雨展開、オーロンゲの壁＋すてゼリフでラグラージを守る。ヤバソチャのおもてなし＋いかりのこなで攻撃機会を最大化。相手の天候・積みにはオーロンゲのいたずらごころで先手を取る。

| トリックルーム展開 | ヤバソチャのトリックルーム上書き |
| エレクトロビーム・でんじほう | ペリッパーのワイドガード |

## 基本選出・立ち回り

### 選出パターン①：壁雨エース（メインプラン）

| ターン | 左（オーロンゲ） | 右（ペリッパー） |
|---|---|---|
| T1 | リフレクター or ひかりのかべ（優先+1） | あめふらし発動 + おいかぜ or ウェザーボール |
| T2 | すてゼリフ → **メガラグラージ**に交代 | ぼうふう / ウェザーボール |
| T3〜 | ウェーブタックル連打（すいすいS224） | 火力サポート or まもる |

### 選出パターン②：キラフロル軸（物理受け系が多い相手）

```
ペリッパー + メガキラフロル を前に出す
→ ヤバソチャのいかりのこなでキラフロルを守りながらC200で崩す
→ ブリジュラスが雨エレクトロビームで詰める
```

### 選出パターン③：対トリルパ

```
オーロンゲ（先手でひかりのかべ） + ヤバソチャ（トリックルーム上書き）
→ 相手のトリルを無力化してから通常選出へ
```
